## Stop gate verdict

The historical tinygrad DEBUG=2 node median for
`q4k_g3_lanemap_gemv_4096_4096` is `9.25 us` per core (72 occurrences, of which
the semantic manifest assigns 36 to non-fused attention-Q).  The isolated exact
full primitive's `6.167 us` is directionally favorable even though it includes
q8 production.  It therefore clears only the *isolated-oracle* gate.

It conflicts with the previous llama trace arithmetic quoted for this role
(`3.072 + 9.536 = 12.608 us` q8 plus MMVQ).  Those two facts cannot both be used
as the same timing quantity.  Before any one-role or 36-role CUDA-graph rewire,
the campaign must reconcile trace node identity/duration units against a fresh
single-role CUDA event measurement.  No family wall delta is claimed, and no
residual-ledger credit is booked from this result.
