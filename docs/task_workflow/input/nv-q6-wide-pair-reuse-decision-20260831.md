# NV Q6 wide aligned-pair and phase-reuse decision

## Decision

Promote the aligned-pair K64 loop expression as the default wide `unroll=2`
route. Reject all four phase-invariant value-reuse arms. None beats the
same-topology aligned-pair control, and the broad high-bit arm spills.

The promoted change is not value reuse. It makes the already-enforced even
Stream-K range invariant visible to NVRTC and removes its unreachable odd-trip
cleanup body.

## Fixed contract

- Shape: `M=512, N=4096, K=12288`, Q6_K FFN down.
- Ownership: 170 persistent owners, 128 output tiles.
- Owner boundary quantum: eight K64 phases.
- Tile K length: 192 K64 phases.
- Packed weight, Q8 record, shared layout, phase math, owner/fixup mapping, and
  output are unchanged.
- Each executed K64 phase retains its original MMA and two barrier lifecycle.

## Pair-alignment proof

The qualifier enumerated every owner/tile intersection generated by the exact
integer formulas in the transform:

- Owners: 170.
- Owner/tile segments: 290.
- `k_begin`, `k_end`, and segment length are even for all 290 segments.
- All observed boundaries are multiples of eight.
- Violations: zero.
- Output segment census: 94 tiles with two segments and 34 with three.

The pair transform calls this enumeration and fails closed if any segment is
not pair-aligned.

## Same-process alternating R31 promotion qualifier

Control and candidate programs were compiled in one process and invoked in
alternating order, reversing call order every round.

| Measurement | Legacy unroll=2 | Aligned pair | Delta |
| --- | ---: | ---: | ---: |
| Main median | 332.864 us | 327.136 us | -5.728 us |
| Main minimum | 328.448 us | 322.240 us | -6.208 us |
| Paired recovery median | - | - | 8.160 us |
| Candidate wins | - | 28 / 31 | - |
| Registers | 250 | 246 | -4 |
| Stack | 0 B | 0 B | 0 B |
| LDL / STL | 0 / 0 | 0 / 0 | 0 / 0 |
| Static IMMA / BAR | 192 / 6 | 128 / 4 | -64 / -2 |
| Static LDG | 144 | 96 | -48 |
| Static address-family ops | 570 | 377 | -193 |

The static instruction reduction is the deleted generic cleanup copy. It does
not reduce logical K work: aligned owner ranges execute the same 192 K64 phases
per output tile.

Both programs produced finite full output with maximum absolute difference
`0.0006866455078125` from the direct compiler reference. Candidate CPU-vs-GPU
fixup maximum difference was zero. Both passed the existing relative/absolute
tolerance gate.

## Selective reuse sweep

All arm timings below are R31 medians compared with the no-reuse aligned-pair
control from the same topology (`327.488 us`, 246 registers, 96 LDG, 377
address-family ops). Fixup stayed at `11.648 us` except the spilling high-bit
arm (`11.776 us`).

| Arm | Reused values per pair | Main | Delta | Regs / stack | LDL / STL | LDG delta | Address delta | Decision |
| --- | --- | ---: | ---: | --- | --- | ---: | ---: | --- |
| A metadata | D words `val34/35` | 335.584 us | +8.096 us | 254 / 0 B | 0 / 0 | -2 | -2 | Reject |
| B high bits | `val0..15` | 413.344 us | +85.856 us | 255 / 136 B | 82 / 84 | -16 | -16 | Reject spill |
| C address | `alu77..80` | 334.688 us | +7.200 us | 246 / 0 B | 0 / 0 | 0 | -11 | Reject |
| D bounded words | `val0/8/16/23` | 329.216 us | +1.728 us | 248 / 0 B | 0 / 0 | -4 | -4 | Reject |

Arm A cannot legally reuse the two scale words: `val31/32` depend on
`(Ridx0&3)<<1` and change between adjacent K64 phases. It therefore reuses only
the invariant block D words. Q8 records are phase-specific in every arm.

No independent value-reuse win exists, so there is no combined reuse variant.

## Facts versus inference

Facts:

- All numerical, timing, range, segment, SASS, and resource values above come
  from the committed R31 JSON evidence.
- The high-bit arm spills and is 85.856 us slower than its topology control.
- The aligned-pair candidate wins the alternating qualifier without stack or
  local-memory traffic.

Inference:

- The aligned-pair gain is explained by eliminating an impossible generic
  cleanup body and lowering register pressure, not by reducing executed model
  math.
- Extending Q6 word lifetime is counterproductive at the current occupancy and
  register point even when it deletes global loads.
